FourSight

A personal analytics app for one creator's own social media accounts.

FourSight is a private Windows and Android app built by and for one person: the creator of the One Fat Man's Journey channel. It reads the analytics for that creator's own TikTok, YouTube, Facebook Page and Instagram accounts through each platform's official API, so the numbers can be viewed and compared in one place.

FourSight is not a public service. It isn't offered to other users, it has no sign-ups, and it isn't sold.

What it does

  • Reads views, likes, comments, shares, followers and similar statistics for the owner's own accounts.
  • Keeps a daily history of those numbers so trends can be charted.
  • Lets the owner post their own videos to their own accounts, only after they confirm each post.

Contact

Questions about FourSight can be sent by opening an issue at github.com/RMac0001/foursight-site/issues.
